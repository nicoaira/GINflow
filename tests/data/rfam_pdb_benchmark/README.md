# GINflow Rfam/PDB retrieval benchmark

This directory contains a 40-family retrieval benchmark. It retains the
original 20 PDB-backed families from
`research-gine-rna-encoder/dataset/rfam_pdb_families` and adds 20 feasible
families from the companion
`research-gine-rna-encoder/dataset/rfam_families` dump. The additional records
use the same molecule schema but are not PDB-backed. It is generated by
[`scripts/prepare_rfam_pdb_benchmark.py`](../../../scripts/prepare_rfam_pdb_benchmark.py).

## Files

- `queries.tsv` — one query per family with only GINflow's mandatory columns.
- `queries_with_windows.tsv` — the same queries plus `start`/`end` core
  windows. Coordinates are 0-based, half-open, as required by GINflow.
- `rouskin_sample_6k.cleaned.4k.tsv`, `rouskin_sample_30k.cleaned.17k.tsv`, and
  `rouskin_sample_150k.cleaned.74k.tsv` — clan-cleaned backgrounds followed by
  the twelve selected mates per family.
- `family_summary.tsv` and `selections.tsv` — query, target, identity-bin, and
  source-record audit trails.
- `selected_models.tsv`, `cmscan_hits.tsv`, `removed_background_ids.tsv`, and
  `cleaning_summary.tsv` — the Rfam model and background-cleaning audit.
- `run_metadata.json` — source checksums and exact preparation parameters.

## Selection protocol

The documented 20 families were retained. Twenty additional feasible families
were selected from the companion Rfam-family dump in numeric accession order.
For each family, the query maximizes the number of available four-member slots,
then the weakest-bin count, then total available mates; the source molecule ID
breaks ties. Four targets per bin were selected at evenly spaced identity ranks
within that bin. Identity is computed over shared Rfam seed match columns:
`>70%`, `55-70%` (including both boundaries), and `<55%`.

All selected families have 12 targets in this build (480 targets
total), with four targets in each bin. The source molecule chosen as the query
is not appended to either background.

## Family provenance

The original 20 families are PDB-backed records from
`dataset/rfam_pdb_families`. The additional 20 families are Rfam-family
records from `dataset/rfam_families`; their structures are annotations from
that companion dump rather than PDB-backed structures.

## Clan-cleaning protocol

The current Rfam seed was split into one Stockholm alignment per selected
family and per member of its Rfam clan. Each alignment was built with
`cmbuild --hand`, calibrated with `cmcalibrate` before search, combined into a
pressed CM database, and searched with `cmscan` at E-value `< 0.01`.
The calibration used `-L 0.01` Mb and seed
`42`; this is recorded because full default calibration is
substantially slower. The scan used the default Infernal heuristic filters
unless `--cmscan-max` was supplied.
The 6k table is an exact subset of the 30k table, and the 30k table is the
unchanged prefix of the 150k table.
The 53-model scan from the original 20-family run and the 28-model scan for the
additional families were merged for the 30k prefix. The additional 120,804
molecules were then scanned against the combined 81-model database in 256
chunks. Thus the 150k cleaning is equivalent to scanning all 150,000 molecules
once with all 81 selected models.

| background | source | input rows | cleaned output |
|---|---|---:|---|
| rouskin_6k | `tests/data/rouskin_sample_6k.tsv` | 5840 | `rouskin_sample_6k.cleaned.4k.tsv` |
| rouskin_30k | `tests/data/rouskin_sample_30k.tsv` | 29196 | `rouskin_sample_30k.cleaned.17k.tsv` |
| rouskin_150k | `tests/data/rouskin_sample_150k.tsv` | 150000 | `rouskin_sample_150k.cleaned.74k.tsv` |

Any input molecule with at least one reported hit below the threshold to any
selected-family or clanmate CM was removed. The selected 12 family mates are
then appended intentionally as positives. No sequences or structures were
refolded or otherwise modified.

## GINflow usage

Build a database from either cleaned background:

```bash
nextflow run . -profile docker \
  --input tests/data/rfam_pdb_benchmark/rouskin_sample_30k.cleaned.17k.tsv \
  --outdir results/rfam-pdb-30k
```

Use `rouskin_sample_150k.cleaned.74k.tsv` in the same command for the 150k
background, for example with `--outdir results/rfam-pdb-150k`.

Search it with the mandatory query sheet:

```bash
nextflow run . -profile docker \
  --query tests/data/rfam_pdb_benchmark/queries.tsv \
  --database results/rfam-pdb-30k/index \
  --outdir results/rfam-pdb-30k-search
```

Use `queries_with_windows.tsv` for a core-only query run. Its `start` and
`end` values select the Rfam-aligned part without the molecule's flanks.
